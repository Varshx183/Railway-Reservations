# Project history

This is the project owner's Railway Reservation System, repaired and extended from its original archive `RailwayReservationSystem-main.zip`.

The original database document identifies the work as **CS301 – Introduction to Database Systems**. Source comments contain contributor names; those comments were not used to establish project ownership.

The repaired implementation retains its Java/TCP/PostgreSQL approach, simplified coach capacities, berth patterns, and the sample timetables from `test.c`. It replaces the original Java classes and SQL layout with packaged classes, normalized tables, safer booking transactions, a JSON protocol, and regression tests.

No project-level license has been selected for this package. Dependency licenses remain those of their respective authors.

AI assistance was used to repair, implement, document, and test this version.
